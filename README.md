# Lucie Command Center

PROMPT LOVABLE

Tu es un Senior Product Designer spécialisé SaaS B2B.

Tu dois créer une application web moderne appelée Lucie Command Center.

Le but n’est PAS de créer une présentation PowerPoint.

Le but est de créer un véritable outil interactif utilisé pendant les rendez-vous commerciaux de Spark Media Marketing.

Le résultat doit donner l’impression que Lucie est déjà un logiciel premium comparable à Hubspot, Salesforce ou Notion.

Le design doit être minimaliste, premium, moderne.

Contraintes

Ne jamais utiliser un style PowerPoint.

Le rendu doit ressembler à une plateforme SaaS professionnelle.

Tout doit être animé avec des transitions douces.

Les KPI doivent être interactifs.

Les cartes doivent être modernes.

Les boutons doivent avoir un effet hover.

Le code doit être propre, modulaire et facilement modifiable.

Objectif final : lorsque je partage mon écran en rendez-vous (R2), le prospect doit avoir l’impression que je lui présente un logiciel propriétaire haut de gamme, et non un simple support commercial.
